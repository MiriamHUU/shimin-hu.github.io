A line of EEG experiments probing how the brain estimates numerosity — the perceived count of items in a visual scene — and how that estimate is shaped by low-level visual features like color coherence, depth cues, and object size.

- **Experimental design**: built multiple controlled paradigms (e.g. color-coherence and depth-cue manipulations) with custom MATLAB/PsychoPy stimulus generation
- **Data collection**: ran EEG sessions and built the accompanying analysis pipelines
- **Analysis**: statistical modeling of behavioral and neural (EEG) responses to isolate the contribution of visual features to numerosity judgments
